# Luminescent

Scroll-animated product page for a fictional watch: pinned hero, image sequence on
scroll, specification panels and a purchase CTA. Design-to-code rebuild.

**Live:** https://luminescent.netlify.app

## Stack

React - Vite - Tailwind - react-icons.

## Run

```bash
git clone https://github.com/ErfanBagheri404/luminescent.git
cd luminescent
npm install
npm run dev
```

Imagery is in `src/assets/`; the page is a single route in `src/App.jsx`.
